**Customer Churn Prediction (Supervised Machine Learning)**

This project uses the Telco Customer Churn dataset to build machine learning models that predict whether a customer will leave a service.

The workflow includes data cleaning, exploratory data analysis (EDA), feature scaling, model training, and model evaluation.

Two supervised learning models were implemented:

Logistic Regression

Random Forest Classifier

EDA was conducted using visualisations such as a correlation heatmap to explore relationships between variables and identify factors associated with churn.

Model performance was evaluated using confusion matrices and accuracy scores. In this case, the Logistic Regression model outperformed the Random Forest model in predicting customer churn.

Libraries used:
pandas,
matplotlib,
seaborn,
scikit-learn
